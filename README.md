# Tic-Tac-Toe

A responsive Tic-Tac-Toe game built with React and Next.js as part of a Software Developer technical assessment.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Features

- Two-player Tic-Tac-Toe gameplay
- Turn tracking
- Win detection
- Draw detection
- New Game functionality
- Responsive design

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser to view the app.
